# Thai Agriculture & Climate Intelligence Dashboard 🌾📊

ระบบแดชบอร์ดอัจฉริยะสำหรับวิเคราะห์ข้อมูลสถิติการผลิตสินค้าเกษตร ความสัมพันธ์กับสภาพภูมิอากาศ และการตรวจจับสัญญาณความเสี่ยงทางการเกษตรของประเทศไทย พัฒนาขึ้นโดยใช้ข้อมูลจริงจากหน่วยงานภาครัฐเพื่อการนำเสนอเชิงวิชาการและการตัดสินใจเชิงนโยบาย

## 1. วัตถุประสงค์และเป้าหมายของระบบ (Objectives)

1. **เข้าใจโครงสร้างการผลิตสินค้าเกษตรไทย:** สำรวจปริมาณผลผลิต พื้นที่เพาะปลูก และบทบาทของแต่ละจังหวัดทั่วประเทศ (77 จังหวัด 26 สินค้าเกษตร)
2. **ติดตามประสิทธิภาพและผลิตภาพ:** วิเคราะห์การเปลี่ยนแปลงของเนื้อที่เก็บเกี่ยว ผลผลิตต่อไร่ (Yield) และอัตราการเก็บเกี่ยว (Harvest Ratio)
3. **สำรวจความสัมพันธ์กับสภาพภูมิอากาศ:** วิเคราะห์ความสัมพันธ์ระหว่างปริมาณฝน อุณหภูมิสูงสุด-ต่ำสุด และความชื้นสัมพัทธ์ กับผลผลิตทางการเกษตรอย่างมีหลักฐานเชิงประจักษ์
4. **ตรวจจับสัญญาณความเสี่ยง (Risk Monitoring):** ระบุพื้นที่และพืชที่มีอัตราการเก็บเกี่ยวต่ำกว่าเกณฑ์มาตรฐาน (ต่ำกว่า 90%) และจัดอันดับความผันผวนของผลผลิต (CV)
5. **ประสบการณ์ผู้ใช้ที่เชื่อมโยง:** รองรับการกรองตามปี จังหวัด และสินค้าเกษตร โดยทุกกราฟ แผนที่ และตารางตอบสนองต่อตัวกรองเดียวกันอย่างสอดคล้อง

## 2. โครงสร้าง Dashboard (3 Tabs Architecture)

ระบบประกอบด้วย 3 แท็บการวิเคราะห์หลัก:

### 🗺️ TAB 1: ภาพรวมประเทศไทย (Thailand Overview)
- **KPI Cards:** ผลผลิตรวม (ตัน), เนื้อที่เพาะปลูก (ไร่), เนื้อที่เก็บเกี่ยว (ไร่), ผลผลิตต่อไร่แบบถ่วงน้ำหนัก (กก./ไร่), อัตราการเก็บเกี่ยว (%), และการเติบโตรายปี (YoY %)
- **Interactive Thailand Choropleth Map:** แผนที่แสดงขอบเขต 77 จังหวัด สลับตัวชี้วัดได้ (ผลผลิต, พื้นที่เพาะปลูก, พื้นที่เก็บเกี่ยว, Yield, อัตราเก็บเกี่ยว, ปริมาณฝน HII) พร้อม Tooltip รายละเอียด และสถานะ "ไม่มีข้อมูล (No Data)" แยกจากค่าศูนย์อย่างชัดเจน
- **Top 10 Rankings:** กราฟจัดอันดับ 10 จังหวัด และ 10 สินค้าเกษตร ตามตัวชี้วัดที่เลือก
- **Historical Trend Chart:** กราฟแนวโน้มรายปี พ.ศ. 2550–2562 ของพื้นที่หรือสินค้าที่เลือก

### 🌦️ TAB 2: สภาพอากาศกับผลผลิต (Climate Impact)
- **เจาะลึกสถานีอุตุนิยมวิทยาสุพรรณบุรี:** วิเคราะห์ข้อมูลตรวจวัดจริงจากสถานีต่อเนื่อง 13 ปี (พ.ศ. 2550–2562) คู่กับผลผลิตการเกษตรจังหวัดสุพรรณบุรี
- **การวิเคราะห์ฝนเชิงพื้นที่ HII (IDW):** วิเคราะห์ฝนเชิงพื้นที่ 77 จังหวัดทั่วประเทศ (พ.ศ. 2561–2562)
- **แนวโน้มฝนสะสมภาพรวมประเทศ:** วิเคราะห์ฝนเฉลี่ยทั้งประเทศ (1970–2025) เทียบผลผลิตรวมระดับประเทศ
- **Scatter Plot & OLS Trendline:** วิเคราะห์ความสัมพันธ์แบบสองตัวแปร (Rainfall vs Yield, Temp vs Yield) พร้อมค่า Pearson $r$, Spearman $\rho$, และ $p$-value
- **Correlation Heatmap:** เมทริกซ์สหสัมพันธ์ระหว่างตัวแปรสภาพอากาศและผลผลิต
- **Scientific Interpretation Panel:** ระบบสร้างคำอธิบายผลลัพธ์ทางสถิติอัตโนมัติ พร้อมข้อควรระวังทางวิชาการ (Correlation ไม่ใช่ Causation)

### ⚠️ TAB 3: ประสิทธิภาพและความเสี่ยง (Production & Risk)
- **Harvest Ratio Monitoring:** แถบปรับเกณฑ์อัตราการเก็บเกี่ยว (ค่าเริ่มต้น 90%) พร้อมติดธงเตือน `⚠️ สัญญาณตรวจทาน` สำหรับรายการที่หลุดเกณฑ์
- **Area vs Yield Quadrants:** กราฟ Scatter Plot แบ่ง 4 กลุ่มผลิตภาพ โดยใช้ค่ามัธยฐาน (Median) ของพื้นที่และ Yield
- **Year-over-Year Analysis (YoY):** กราฟแท่งแสดงอัตราการเติบโตรายปี (สีเขียว = เติบโต, สีส้มแดง = หดตัว)
- **Volatility Analysis (CV %):** ตารางจัดอันดับสินค้าเกษตรตามค่าสัมประสิทธิ์ความแปรปรวน (CV) ในรอบ 13 ปี
- **Risk & Review Data Table:** ตารางค้นหา กรอง และมีปุ่มดาวน์โหลดข้อมูลตารางความเสี่ยงเป็นไฟล์ CSV

## 3. สูตรและนิยามตัวชี้วัดทางการเกษตร (Formulas & Definitions)

- **ผลผลิตต่อไร่แบบถ่วงน้ำหนัก (Weighted Yield):**
  $$\text{Weighted Yield (กก./ไร่)} = \frac{\sum \text{ผลผลิต (ตัน)} \times 1,000}{\sum \text{เนื้อที่เก็บเกี่ยว (ไร่)}}$$
  *(คำนวณแบบถ่วงน้ำหนักเสมอ ไม่ใช้ค่าเฉลี่ยธรรมดาของ Yield รายแถวเพื่อป้องกันความเอนเอียง)*

- **อัตราการเก็บเกี่ยว (Harvest Ratio):**
  $$\text{Harvest Ratio (\%)} = \frac{\sum \text{เนื้อที่เก็บเกี่ยว (ไร่)}}{\sum \text{เนื้อที่เพาะปลูก (ไร่)}} \times 100$$

- **เนื้อที่ไม่ได้เก็บเกี่ยว (Unharvested / Damaged Area):**
  $$\text{Unharvested Area (ไร่)} = \sum \text{เนื้อที่เพาะปลูก} - \sum \text{เนื้อที่เก็บเกี่ยว}$$

- **การเปลี่ยนแปลงรายปี (Year-over-Year Growth):**
  $$\text{YoY (\%)} = \frac{\text{ค่าปีปัจจุบัน} - \text{ค่าปีก่อนหน้า}}{\text{ค่าปีก่อนหน้า}} \times 100$$
  *(กรณีปีก่อนหน้าเป็นศูนย์หรือไม่มีข้อมูล จะแสดงเป็น N/A)*

- **สัมประสิทธิ์ความแปรปรวน (Coefficient of Variation):**
  $$\text{CV (\%)} = \frac{\text{ส่วนเบี่ยงเบนมาตรฐาน (SD)}}{\text{ค่าเฉลี่ย (Mean)}} \times 100$$

- **กฎการรวมข้อมูล (Double-Count Prevention):**
  ระบบแยกแถวระดับประเทศ (`ทั้งประเทศ`) และระดับภูมิภาค (`ภาคเหนือ`, `ภาคกลาง`, `ภาคใต้`, `ภาคตะวันออกเฉียงเหนือ`) ออกจากระดับจังหวัดอย่างเข้มงวด การรวมยอดระดับประเทศคำนวณจากผลรวมของ 77 จังหวัด ป้องกันการนับซ้ำ 100%

## 6. การติดตั้งและเริ่มใช้งาน (Installation & Quickstart)

### ขั้นตอนที่ 1: ตรวจสอบ Python
ระบบรองรับ Python 3.11 หรือสูงกว่า (ทดสอบและยืนยันบน Python 3.14.7)

### ขั้นตอนที่ 2: ติดตั้ง Dependencies
เปิด Terminal หรือ PowerShell ในโฟลเดอร์โปรเจกต์ แล้วรันคำสั่ง:
```bash
pip install -r requirements.txt
```

### ขั้นตอนที่ 3: รันการทดสอบ Unit Tests
ทดสอบความถูกต้องของสูตรคำนวณและการทำความสะอาดข้อมูล:
```bash
python -m pytest tests/test_pipeline.py -v
```
*(ผลลัพธ์ที่คาดหวัง: ผ่านครบทุกการทดสอบ 18/18 tests passed)*

### ขั้นตอนที่ 4: เปิดใช้งานแดชบอร์ด
รันคำสั่ง:
```bash
streamlit run app.py
```
หรือ:
```bash
python -m streamlit run app.py
```
เปิดเบราว์เซอร์ไปที่: `http://localhost:8501`

## 7. ข้อควรระวังทางวิชาการ (Academic Caveats)

1. **สหสัมพันธ์มิใช่เหตุและผล (Correlation is NOT Causation):** การพบความสัมพันธ์ระหว่างปริมาณน้ำฝนหรืออุณหภูมิกับผลผลิต ไม่ได้หมายความว่าสภาพอากาศเป็นปัจจัยเดียวที่กำหนดผลผลิต เนื่องจากยังมีปัจจัยแทรกซ้อน เช่น การจัดการน้ำในระบบชลประทาน โรคระบาดพืช การใส่ปุ๋ย และราคาผลผลิต
2. **ขอบเขตข้อมูลสภาพอากาศ:** ข้อมูลสถานีสุพรรณบุรีนำมาวิเคราะห์คู่กับข้อมูลเกษตรเฉพาะของจังหวัดสุพรรณบุรีเท่านั้น ไม่มีการนำข้อมูลนี้ไปแทนค่าในจังหวัดอื่นโดยเด็ดขาด
3. **การประมาณค่าเชิงพื้นที่:** ข้อมูลฝนรายจังหวัดจาก HII เป็นค่าประมาณการเชิงพื้นที่ด้วยเทคนิค Inverse Distance Weighting (IDW) จากสถานีตรวจวัดของกรมอุตุนิยมวิทยา มิใช่การตรวจวัดจริงทุกจุดในจังหวัด
