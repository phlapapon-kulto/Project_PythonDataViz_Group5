# Thai Agriculture & Climate Intelligence Dashboard 🌾📊
### Real Open Data Edition for Thai Farmers & Agricultural Research

ระบบแดชบอร์ดอัจฉริยะวิเคราะห์ข้อมูลการผลิตสินค้าเกษตรและภูมิอากาศของประเทศไทย ออกแบบตามโครงสร้าง Information Hierarchy ระดับมืออาชีพ โดยเชื่อมโยงข้อมูลจริงจากแหล่ง Open Data ภาครัฐที่ตรวจสอบย้อนกลับได้ (สศก., กรมอุตุนิยมวิทยา, สสน. HII, กรมชลประทาน, กรมพัฒนาที่ดิน, ปภ., DOAE) ปราศจากข้อมูลจำลอง (Zero Mock Data) 100% พร้อมการทดสอบ Unit Tests และ Streamlit AppTest ผ่านครบถ้วน 51 รายการ

## 1. วัตถุประสงค์และเป้าหมายของระบบ (Objectives)

1. **เข้าใจโครงสร้างการผลิตสินค้าเกษตรไทย:** สำรวจเนื้อที่เพาะปลูก เนื้อที่เก็บเกี่ยว และผลผลิตของ 77 จังหวัดทั่วประเทศ ครอบคลุม 26 สินค้าเกษตร โดยมีทางลัดพืชเศรษฐกิจหลัก: **ข้าวนาปี**, **ข้าวนาปรัง**, **มันสำปะหลัง**, และ **ข้าวโพดเลี้ยงสัตว์**
2. **แดชบอร์ด 4 แท็บวิเคราะห์เชิงลึก:** ออกแบบโครงสร้าง Dashboard ให้กระชับ ตรงเป้าหมาย แบ่งออกเป็น 4 แท็บหลักที่ตอบสนองต่อ Global Filters ร่วมกัน
3. **Global Filter Bar ด้านบน:** แถบตัวกรองระดับบนสุดประกอบด้วย ภูมิภาค (Region), จังหวัด (Province แบบ Dynamic ตามภาค), ชนิดพืช (Crop ทั้งหมด 26 ชนิด), ปี พ.ศ. (2550–2562), และตัวชี้วัดหลัก พร้อมปุ่ม Reset และแถบแสดงสถานะตัวกรอง (Active Filter Badges)
4. **แผนที่ประเทศไทยและกราฟเปรียบเทียบ:** Choropleth Map แสดงการกระจายตัวตาม 77 จังหวัด คู่ขนานกับกราฟเปรียบเทียบแนวโน้มประวัติศาสตร์รายปี
5. **สภาพอากาศและสถานการณ์เพาะปลูก:** วิเคราะห์ความสัมพันธ์ระหว่างฝนเชิงพื้นที่ 77 จังหวัด (HII IDW), ฝนสะสมช่วงฤดูเพาะปลูก (พ.ค.–ต.ค.), อุณหภูมิ และสถานีตรวจวัด TMD กับผลผลิต
6. **ปัจจัยขับเคลื่อนผลผลิต:** วิเคราะห์ปัจจัยด้านระบบชลประทาน (RID), ความเหมาะสมของดินตามระบบ Agri-Map (LDD), ภัยแล้งและอุทกภัย (DOAE/DDPM) และเทคโนโลยีเครื่องจักรกล
7. **เศรษฐศาสตร์ฟาร์มและเครื่องคำนวณกำไร:** วิเคราะห์ราคาหน้าฟาร์มจริงของ สศก., โครงสร้างต้นทุนการผลิต และเครื่องคำนวณกำไรสุทธิและจุดคุ้มทุนที่แยกข้อมูลเกษตรกรออกจากเกณฑ์ภาครัฐอย่างชัดเจน

## 2. สถาปัตยกรรมแดชบอร์ด 4 แท็บ (4-Tab Architecture)

ระบบจัดกลุ่มการวิเคราะห์ออกเป็น 4 แท็บหลักตามการจัดลำดับชั้นข้อมูล (Information Hierarchy):

### 📊 TAB 1: ภาพรวมการผลิตสินค้าเกษตร (Overview)
- **แถวที่ 1 (KPI Cards 4 ตัวชี้วัดหลัก):**
  - เนื้อที่เพาะปลูก (ไร่) พร้อมส่วนต่างและ % การเปลี่ยนแปลงเทียบกับปีก่อนหน้า (YoY)
  - เนื้อที่เก็บเกี่ยว (ไร่) พร้อมส่วนต่างและ % การเปลี่ยนแปลง YoY
  - ปริมาณผลผลิตรวม (ตัน) พร้อมส่วนต่างและ % การเปลี่ยนแปลง YoY
  - ผลผลิตต่อไร่แบบถ่วงน้ำหนัก (กก./ไร่) พร้อมส่วนต่างและ % การเปลี่ยนแปลง YoY
- **แถวที่ 2 (แผนที่และการเปรียบเทียบรายปี):**
  - **แผนที่ประเทศไทย (Choropleth Map):** แผนที่เชิงปฏิสัมพันธ์แสดงความหนาแน่นตามตัวชี้วัดที่เลือก พร้อม Tooltip รายละเอียดและรหัสจังหวัด
  - **กราฟแนวโน้มรายปี (Historical Trend Line Chart):** เปรียบเทียบข้อมูลย้อนหลัง พ.ศ. 2550–2562
- **แถวที่ 3 (การจัดอันดับจังหวัด):**
  - กราฟแท่ง 10 อันดับจังหวัดสูงสุด (Top 10) และ 10 อันดับจังหวัดต่ำสุด (Bottom 10: เฉพาะที่มีการผลิต > 0)
  - ข้อสังเกตเชิงลึกเรื่องขนาดพื้นที่ vs ประสิทธิภาพผลผลิตต่อไร่ (Scale vs Efficiency)
- **แถวที่ 4 (ตารางข้อมูลรายละเอียด):**
  - ตารางแสดงสถิติระดับภาค จังหวัด ชนิดพืช ปี พื้นที่ ผลผลิต และความเสียหาย
  - ระบบค้นหาข้อความ (Search Box), จัดเรียงลำดับตามคอลัมน์, และปุ่มดาวน์โหลดข้อมูล CSV (utf-8-sig)

### 🌦️ TAB 2: สภาพอากาศและสถานการณ์เพาะปลูก (Climate & Harvest)
- **3 มิติการวิเคราะห์สภาพอากาศจริง:**
  1. ฝนเชิงพื้นที่ 77 จังหวัดทั่วประเทศ (พ.ศ. 2561–2562, สสน. HII IDW)
  2. แนวโน้มฝนสะสมเฉลี่ยระดับประเทศระยะยาว (พ.ศ. 2550–2562, สสน. HII)
  3. สถานีตรวจอากาศเพื่อการเกษตรรายวัน (กรมอุตุนิยมวิทยา TMD Open Data API Catalog `c1-1-3-7`)
- **ความสัมพันธ์ระหว่างฝน อุณหภูมิ และผลผลิต:** Bivariate Scatter Plot พร้อมเส้น OLS Trendline, ค่า Pearson $r$, Spearman $\rho$, $p$-value และขนาดตัวอย่าง $N$
- **การวิเคราะห์ฝนฤดูเพาะปลูก (พ.ค.–ต.ค.):** แสดงให้เห็นว่าช่วงเวลาฝนตกสำคัญกว่าปริมาณฝนสะสมรวมทั้งปี
- **กรอบการแปลผลทางวิชาการ:** แจ้งเตือนเสมอว่า "สหสัมพันธ์ไม่ใช่เหตุและผล (Correlation is NOT Causation)"

### 🚜 TAB 3: ปัจจัยที่เกี่ยวข้องกับผลผลิต (Production Factors)
วิเคราะห์ปัจจัยขับเคลื่อนผลผลิตนอกเหนือจากสภาพอากาศ:
- **ระบบชลประทานและแหล่งน้ำ (RID & OAE):** สัดส่วนพื้นที่ชลประทาน (%) vs ผลผลิตต่อไร่
- **ความเหมาะสมของดินตามระบบ Agri-Map (กรมพัฒนาที่ดิน LDD):** สัดส่วนชั้นความเหมาะสมของดิน S1, S2, S3, N รายจังหวัด
- **ภัยพิบัติธรรมชาติ น้ำท่วมและภัยแล้ง (DOAE & DDPM):** พื้นที่ประสบอุทกภัยและภัยแล้งสะสมรายจังหวัด
- **เทคโนโลยีและโครงสร้างต้นทุน (สศก.):** Donut Chart โครงสร้างต้นทุน (ปุ๋ย สารเคมี เมล็ดพันธุ์ แรงงาน ค่าเช่าที่ดิน) และสัดส่วนการใช้เครื่องจักรกลเกษตร (Mechanization Share %)

### 💰 TAB 4: ราคา ต้นทุน และความคุ้มค่า (Farm Economics)
- **ราคาสินค้าเกษตรหน้าฟาร์มจริง (สศก. 2561–2562):** ราคารายสัปดาห์ 1,979 รายการ, กราฟแนวโน้มราคา และสถิติราคาเฉลี่ย สูงสุด ต่ำสุด
- **เปรียบเทียบต้นทุนต่อหน่วย vs ราคาขาย:** คำนวณส่วนต่างกำไร/ขาดทุนต่อ กก.
- **เครื่องคำนวณกำไรและจุดคุ้มทุน (Farm Profit Calculator):**
  - แยกช่องกรอกของเกษตรกร (พื้นที่, ผลผลิตคาดหวัง, ต้นทุนต่อไร่, ราคาขาย) ออกจากเกณฑ์เฉลี่ยอ้างอิงของ สศก.
  - สูตรคำนวณมาตรฐาน:
    $$\text{Total Cost} = \text{Area} \times \text{Cost per Rai}$$
    $$\text{Total Yield} = \text{Area} \times \text{Yield per Rai}$$
    $$\text{Revenue} = \text{Total Yield} \times \text{Sale Price}$$
    $$\text{Estimated Profit} = \text{Revenue} - \text{Total Cost}$$
    $$\text{Break-even Yield (กก./ไร่)} = \frac{\text{Total Cost}}{\text{Area} \times \text{Sale Price}}$$
    $$\text{Break-even Price (บาท/กก.)} = \frac{\text{Total Cost}}{\text{Total Yield}}$$
  - ข้อจำกัดความรับผิดชอบ (Disclaimer) ว่าผลลัพธ์เป็นการประมาณการมิใช่การรับรองผลประกอบการทางบัญชี

## 4. ผลการทดสอบระบบ (Verification & Testing)

ระบบผ่านการทดสอบอัตโนมัติด้วย `pytest` ครอบคลุม 51 รายการทดสอบ (100% Passed):
- `TestMandatoryDataRemoval`: ตรวจสอบการถอดถอนชุดข้อมูลสถานีเดี่ยวในอดีตออกถาวร
- `TestDataCleaning`: การทำความสะอาดข้อมูล การแปลงปี พ.ศ./ค.ศ. การจัดกลุ่ม 4 ภูมิภาค
- `TestMathematicalFormulas`: สูตรคำนวณผลผลิตถ่วงน้ำหนัก อัตราเก็บเกี่ยว การป้องกันการหารด้วยศูนย์
- `TestDoubleCountingPrevention`: การป้องกันการนับซ้ำระหว่างระดับประเทศและจังหวัด
- `TestAnalyticsAndPlanning`: การคำนวณทางสถิติ สหสัมพันธ์ และการจัดกลุ่มควอดรันต์
- `TestDataLoaderAndFiles`: ความสมบูรณ์ของตัวโหลดข้อมูลและโครงสร้างไฟล์จริง
- `TestEnhancedFeatures`: การโหลดครบ 26 ชนิดพืช และการจัดอันดับ Bottom 10
- `TestCropProductionDrivers`: การเชื่อมโยงข้อมูลชลประทาน ดิน Agri-Map ต้นทุน และภัยพิบัติ
- `TestRedesignedDashboard`: การทดสอบโครงสร้าง 4 แท็บ, การกรองตามภูมิภาค, สูตรคำนวณฟาร์ม และการรัน Streamlit AppTest ไร้ข้อผิดพลาด (0 Exceptions)

```bash
# รันทดสอบทั้งหมด
python -m pytest tests/test_pipeline.py -v
```
